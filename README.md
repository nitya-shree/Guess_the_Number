# Guess the Number 🎲

A simple web-based game where the user tries to guess a random number between 1 and 10.

## 💡 How it works
- Enter a number between 1 and 10.
- Click "Check".
- If your guess is correct, you win!
- If not, you lose one point from your score.
- Game ends when your score reaches 0.
